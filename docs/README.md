# Documentação do Projeto CRM BYTE & Sentinela SecOps

Este diretório contém a documentação gerada para o sistema CRM BYTE. Conforme a regra estabelecida:
1. Deve-se ler a documentação antes de mexer no código.
2. Todas as alterações devem ser documentadas no arquivo `manutencao.md`.

## Estrutura do Sistema
- `/SISTEMA COMPLETO/landing`: Landing Page (HTML/CSS estático).
- `/SISTEMA COMPLETO/frontend`: Aplicação SPA (Vite + Vanilla JS).
- `/SISTEMA COMPLETO/backend`: Backend API.
- `/SISTEMA COMPLETO/biometric-service`: Serviço de validação facial.

Para mais detalhes da arquitetura técnica, consulte o README principal em `/SISTEMA COMPLETO/README.md`.
